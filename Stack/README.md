# Стек

-----------------------

## Описание
Реализация стека на языке `C`, поддерживающая следующие операции:
1. Инициализация
2. Получение количества элементов
3. Получить значение на вершине
4. Положить значение на вершину
5. Достать значение с вершины


Помимо реализации стека файл `main.c` содержит тесты.
