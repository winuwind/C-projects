# Параллельная реализация метода Якоби в трехмерной области

---------------------------

## Описание
Полное описание задачи можно прочитать [здесь](https://ssd.sscc.ru/sites/default/files/content/attach/343/parallel_lab4_2020.pdf).

Реализовано решение уравнения из условия задачи методом Якоби в трехмерной области в случае одномерной декомпозиции области.

Использованы асинхронные функции `MPI`. 

## Требования
Для компиляции и запуска программы необходима установленная библиотека `MPI`, а также компилятор.
