# Фракталы - Множество Мандельброта

------------------------------------

## Описание
Консольное приложение с графикой `SDL2`, отображающее множество Мандельброта.

1. Выделение области мышью - зажатие `ЛКМ/ПКМ`
2. Отображение выделенной области в полный экран - `Enter`
3. Сохранение отображенного изображения в формате `BMP` - `S/Print Screen`. Сохранение в рабочей директории с именем `Mandelbrot_#.bmp`
4. Обновление отрисовки, если не произошло автоматически - `D`
5. Приблизить в 2 раза - `=`
6. Отдалить в 2 раза - `-`
7. Завершить программу - `Escape`

## Ограничение
Платформенные ограничения связанные с используемой библиотекой для графики - `SDL/SDL2`, поддерживаемая только в Windows.

## Зависимости
Необходима установка библиотеки `SDL/SDL2`, или динамической библиотеки SDL2.dll в случае использования скомпилированной программы.
