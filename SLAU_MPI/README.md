# Параллельная реализация решения системы линейных алгебраических уравнений с помощью MPI

-----------------------------------------------

## Описание
Условие задачи можно прочитать [здесь](https://ssd.sscc.ru/sites/default/files/content/attach/343/parallel_lab1_2020.pdf).

Распараллеленная с помощью `MPI` программа, решающая систему линейных алгебраических уравнений методом сопряженных градиентов.

Матрица `A` разрезается по строкам на близкие по размеру части.
Соседние строки матрицы должны располагаться в одном или в соседних MPI-процессах.

Реализованы два варианта программы:
1. Векторы x и b дублируются в каждом MPI-процессе
2. Векторы x и b разрезаются между MPI-процессами аналогично матрице A.

## Требования
Для компиляции и запуска программы необходима установленная библиотека `MPI`, а также компилятор.
