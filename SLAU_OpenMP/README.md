# Параллельная реализация решения системы линейных алгебраических уравнений с помощью OpenMP

-----------------------------------------------

## Описание
Условие задачи аналогично той же [задачи](https://github.com/winuwind/C-projects/tree/main/SLAU_MPI/README.md), но в другой реализации параллельных вычислений.

Реализовано 2 варианта программы:
1. Для каждого распараллеливаемого цикла создается отдельная параллельная секция `#pragma omp parallel for`
2. Создается одна параллельная секция `#pragma omp parallel`, охватывающая весь итерационный алгоритм.

## Требования
Необходима установленная библиотека `OpenMP`.
