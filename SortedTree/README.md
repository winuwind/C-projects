# Дерево

-----------------------

## Описание
Реализация дерева на языке `C`, поддерживающая следующие операции:
1. Создание дерева
2. Получение размера дерева
3. Удаление дерева
4. Добавление элемента в дерево (с учётом сортировки)
5. Добавление/Изменение значения в следующей вершине дерева от переданной
6. Поиск вершины по значению
   1. В отсортированном дереве
   2. В любом дереве
7. Отображение дерева
