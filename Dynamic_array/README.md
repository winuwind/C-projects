# Динамический массив

--------------

## Описание

Библиотека динамического байтового массива, поддерживающая следующие функции:

1. Инициализация массива
2. Добавление одного байта в конец
3. Добавление нескольких байт в конец
4. Получение указателя непосредственно на данные
5. Сброс данных
6. Освобождение данных

Файл `main.c` содержит тесты функционала
