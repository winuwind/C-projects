# Умножение матрицы на матрицу в MPI 2D решетка

----------------------------------

## Описание
Полное описание задачи можно прочитать [здесь](https://ssd.sscc.ru/sites/default/files/content/attach/343/parallel_lab3_2020.pdf).

Реализован параллельный алгоритм умножения матрицы на матрицу при 2D решетке.

## Требования
Для компиляции и запуска программы необходима установленная библиотека `MPI`, а также компилятор.
